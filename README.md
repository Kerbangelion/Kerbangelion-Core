# Kerbangelion
Config, textures, models, functionalities and flags for the Kerbangelion mod (KNGL).

KNGL is based on Sol by Ballisticfox. It works as a sub-mod of Sol and requires it to be installed, with x16 Earth and Moon textures.

The mod features dramatic changes to the Earth:
- The global ocean levels have risen about 100 meters.
- Oceans are now contaminated with LCL
- The earth has two new moons; Lilith's Black Moon, and Adam's White Moon.
- Antarctica, obliterated in Second Impact, is entirely gone. In its place you can find pillars of salt at the south pole.
- Something happened in Nevada.
- Tabgha moon base is available as a launch location (requires [KSCSwitcher-Moon](https://github.com/Dewon2301/KSCSwitcher-Moon)!)
- ... And some more?

To enjoy the full mod's experience, make sure you install the following:
- Kerbangelion Core (this page): main mod
- Kerbangelion-theme : optional theme submod
- Kerbangelion-contracts : optional contracts submod
- KSCSwitcher-Moon : to have Tabgha base on the moon (but it also allows you to make more locations on other planets)
